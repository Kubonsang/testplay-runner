## Result

The v0.11 hardening gates passed on the primary Unity 6 / Windows target. The
bridge proved ownership for normal and sequential runs, refused foreign and
pre-existing-broken states, returned an indeterminate exit 9 without replay
across domain reload, sealed an old-session request after full Editor restart,
and recovered for later warm runs.

The user's GNF_ project then passed its release-candidate acceptance set through
the already-open Editor: 1/1, 3/3, and 49/49, plus an intentional no-match run
that returned exit 10 with zero tests.

### Domain reload / indeterminate terminal

The run that forced a domain reload returned:

- backend: `bridge`
- exit: 9
- tests: 0
- warning: the run may have executed and was not rerun
- terminal events: exactly one `run_finished`, `phase: done`, `exit_code: 9`
- extra cold Unity process: none

The following marker-present run passed through the same warm Editor, proving
that the conservative result did not permanently wedge the bridge.

### Editor restart / stale-session request

An old request bound to session `20260714-114122-3effaa43` was left on disk, the
disposable Editor was fully stopped, and a new Editor session
`20260714-122104-14fa5e39` was started. The new server wrote:

```json
{
  "run_id": "20260714-212000-deadbeef",
  "execution_state": "possibly_started",
  "reason": "request belongs to bridge session '20260714-114122-3effaa43', current session is '20260714-122104-14fa5e39'"
}
```

No response file and no results XML were produced; the test was not executed.

### Pre-existing broken compile

The disposable Editor was first placed into a real `CS0103` failed-compilation
state. A filtered `PassingSmoke` request received a protocol-2 rejection:

```text
script compilation is failing in this editor (pre-existing broken state);
cold run will report the compile errors
```

The CLI selected `backend: "shadow"` and returned exit 2 with zero executed
tests. After the temporary error was removed, the same Editor immediately
returned `backend: "bridge"`, 1/1 pass. This proves both false-green prevention
and recovery.

## Disclosures and limits

- The foreign-run bridge refusal was proven. Its disposable cold-shadow fallback
  later hit an unrelated Unity Curl cache database failure, so that particular
  spike did not claim a cold test result. Cold fallback completion was separately
  proven by the pre-existing-broken-compile spike, which reached authoritative
  shadow exit 2.
- The v0.11 protocol-2 warm bridge requires Unity 6 (6000.3+). Its per-run GUID
  activity and cancellation APIs are absent from Unity 2022.3, so the package
  manifest blocks that unsupported editor instead of risking a completion
  wedge. The official v0.11 revalidation target is Unity 6000.3.10f1 on Windows.
- [Release Preflight run 29342342987](https://github.com/Kubonsang/testplay-runner/actions/runs/29342342987)
  passed on merge commit `b7e59fa7340a86df4953e1ab7de60da7332e85d6` before the
  annotated `v0.11.0` tag was pushed. [Release run 29342533259](https://github.com/Kubonsang/testplay-runner/actions/runs/29342533259)
  then published all five archives and `checksums.txt`. Published tags are
  immutable; a release defect is fixed as v0.11.1, never by moving v0.11.0.
