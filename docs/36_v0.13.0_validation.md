## Unsigned release policy

The maintainer explicitly accepted an unsigned `v0.13.0`. Both Windows
executables are expected to report `NotSigned`; this is disclosed in the
release notes, quickstart, README, and security policy. Publication requires:

- Go 1.26.6 full tests, race tests, vet, module verification, and govulncheck;
- the frozen-provider check and nine-archive inventory;
- SHA-256 verification for every archive;
- GitHub build-provenance attestation for the exact published archives;
- Windows CLI/config/helper CI contracts and an exact draft-state review.

The existing `TrustedStable` harness, signing-proof collector, and DigiCert
integration notes remain available as optional future hardening. No signing
credential is configured and Authenticode is not a v0.13.0 gate.
