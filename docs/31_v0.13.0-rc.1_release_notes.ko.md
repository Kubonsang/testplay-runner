# testplay v0.13.0-rc.1 릴리스 노트

`v0.13.0-rc.1`은 Windows 11 x64에서 native 검증한 Differencing VHDX
workspace provider를 명시적 experimental opt-in으로 제공합니다. 기존
direct-batch와 legacy-shadow 선택은 계속 기본값입니다.

## Differencing VHDX workspace

- compatibility key당 immutable 64 GiB dynamic NTFS parent VHDX 하나를
  commit하고, run마다 private writable differencing child를 만듭니다.
- child volume은 격리 workspace의 `Library`에 directory mount됩니다.
  `Assets`, `Packages`, `ProjectSettings`는 workspace별 physical copy입니다.
- 관리자가 `testplay storage install`을 한 번 실행하여 한 사용자
  SID용 LocalSystem broker를 설치합니다. 이후 CLI와 AI agent는
  비관리자 권한으로 인증된 named pipe를 사용합니다.
- 명시적 `vhdx-diff`는 fallback하지 않습니다. 명시적 `auto`는
  parent/child 작업 전 broker 연결 또는 capacity admission이 실패했을
  때만 `legacy`를 선택할 수 있습니다.
- retained attach/remove, allocated-byte quota, host-free 보호, LRU,
  broker restart/Windows reboot recovery를 포함합니다.

기본 store quota는 host에 실제 allocated된 VHDX 32 GiB, host-free floor는
20 GiB, 신규 child reserve는 2 GiB입니다. physical partition을 format하거나
ReFS, Dev Drive, Defender, registry 설정을 변경하지 않습니다.

## 설치와 무결성

관리자 설치 전 [Differencing VHDX quickstart](vhdx-diff-quickstart.md)를
읽으십시오. RC Windows 바이너리는 Authenticode 서명이 없어 Windows
SmartScreen 경고가 나타날 수 있습니다. 실행을 승인하기 전에
`checksums.txt`와 GitHub provenance를 모두 검증하십시오.

```powershell
gh attestation verify `
  .\testplay_0.13.0-rc.1_windows_amd64.zip `
  -R Kubonsang/testplay-runner
```

릴리스 workflow는 먼저 draft prerelease를 생성합니다. 공개 전 exact draft
Windows asset으로 native RC smoke를 통과해야 합니다.
